# Gauss-Jordan Modular

## Objetivo
Implementar Gauss-Jordan reutilizando Gauss.eliminacionGaussiana()

## Estructura
- defmatrizz.java: define matriz aumentada
- Gauss.java: triangulacion
- GaussJordan.java: normaliza a 1 y barrido superior
- Lanzador_gausjordan.java: lanza y lee solucion directa

## Compilar y Ejecutar
javac src/*.java
java -cp src Lanzador_gausjordan

## Salida
Soluciones del sistema (Gauss-Jordan):
x1 = 2.0
x2 = 3.0
x3 = -1.0
